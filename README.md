# Elevator Control System Simulator with simple AI Agents

This project was produced using a Windows WPF application as a simple way to include graphical representations in a C# script. Admittedly this should have been written as multiple smaller files/scripts but it grew slowly in complexity and ended up being one long file. This project uncludes custom sprites, and was produced as a final project for my Data Structures and Algorithms class.
